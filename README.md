# Golka GTB Mini App

`index.html` — весь интерфейс в одном файле: стили, SVG-иконки и JavaScript уже внутри. Сборка, npm, React и отдельные картинки не нужны. Единственный внешний скрипт — официальный Telegram Web App SDK.

## GitHub Pages

1. Положите `index.html` в корень репозитория (или в выбранную папку `docs`).
2. GitHub → Settings → Pages → Deploy from a branch → нужная ветка и папка.
3. Дождитесь публикации и откройте полученный HTTPS-адрес, например `https://USERNAME.github.io/REPOSITORY/`.
4. В BotFather выберите бота → Bot Settings → Configure Mini App. Укажите этот адрес для главного мини-приложения; при необходимости такой же адрес поставьте на кнопку меню.
5. Откройте приложение из Telegram. Авторизация идёт по подписанному `Telegram.WebApp.initData`.

## Подключение к боту

В начале JavaScript есть **публичная**, не секретная настройка:

```js
const API_BASE = 'https://golka-gtb-api.j.onjrnm.co.uk';
```

Адрес уже настроен в готовом файле. Он указывает на работающий сервер бота. Менять его для загрузки на GitHub не нужно. Токен бота, DeepSeek и другие ключи сюда добавлять нельзя.

GitHub Pages размещает только интерфейс. Серверный файл `modbot/miniapp.py` работает рядом с ботом и SQLite; он проверяет HMAC-подпись Telegram, срок сессии и права пользователя на каждое действие. `initDataUnsafe` для выдачи доступа не используется. Подпись и секреты в localStorage не сохраняются. В localStorage остаётся только номер выбранной группы.

Без открытия из Telegram приложение запускает явно обозначенную демонстрацию. В Telegram отсутствие сервера или ошибка авторизации **не** заменяются фиктивными успешными изменениями: пользователь получает ошибку.

## Что работает внутри приложения

- Выбор доступной группы, роли, тариф и состояние бота.
- Статистика проверок за текущие сутки UTC и число участников.
- Общая модерация, ИИ-модерация, антиспам, антифлуд, режим, уведомления.
- Редактор правил ИИ, защита от перезаписи чужих изменений.
- Функции группы: игры, РП, отдельные команды, магазин, фермы, инвестиции.
- Кошелёк, работа и обучение, опыт, уровни и таймеры.
- Чат с ИИ: общая квота в процентах, выбор Flash/Pro, промпт и веб-поиск.
- Настройки поведения ИИ: мат, грубость, длина, крик, темы, языки, шутки и ссылки; отдельные для каждой группы.
- Руководство в профиле: 27 разделов с поиском по темам. Внутренний бюджет и стоимость запросов ИИ не показываются.
- Посёлок, защищённая загрузка карты, список построек и прогресс.
- Активные розыгрыши, журнал настроек, профиль, правила и версии.

Переводы, покупки, фермы, инвестиции, улучшения, создание розыгрышей, стройка, категории модерации и подключения ИИ управляются через формы внутри мини-приложения. Они используют существующую серверную логику, цены, подтверждения и проверки прав. Оплата Stars открывается в штатном окне Telegram. Состояние форм отделено от личного диалога с ботом.

Кошелёк: переключаемые свайпом карты C₲ и ⚡ с перспективой соседней карты; личная история операций отдельно по валютам с загрузкой следующих страниц. Примерные операции показываются только в явно обозначенном деморежиме.

Правила участников показываются текстом; редактировать их вместе с картинками, форматированием и кастомными эмодзи нужно в боте. Мини-приложение не перезаписывает эти данные.

## Сервер

API слушает порт `7080` внутри контейнера; `MINIAPP_API_PORT=0` его отключает. Владелец подтвердил открытие HTTPS-прокси для GitHub Pages. Приложение не запускает второй экземпляр Telegram polling.

- `GET /health` — состояние, без пользовательских данных.
- `GET /miniapp/v1/me` — профиль и доступные группы.
- `GET /miniapp/v1/guide` и `/guide/{category}` — список и текст разрешённых категорий руководства после авторизации Telegram.
- `GET /miniapp/v1/groups/{id}` — разрешённые пользователю данные группы.
- `POST .../settings` — отдельная настройка с проверкой роли и версии.
- `POST .../features` — переключение разрешённой функции.
- `POST .../daily` — работа или обучение с ключом идемпотентности.
- `POST .../panel` — встроенные формы с одноразовыми непрозрачными токенами действий.
- `POST .../history` — личная история, фильтр по валюте и курсор страницы.
- `GET .../map` — карта посёлка без раскрытия токена Telegram.

Запросы защищены заголовком `Authorization: tma <initData>`. Срок сессии — час; затем приложение нужно открыть заново. Размеры HTTP-запросов, время обработки, подключения и частота запросов ограничены. API не использует cookie. CORS разрешён только для `https://golkatok.github.io`; при переезде добавьте точный origin в `MINIAPP_ALLOWED_ORIGINS` (через запятую, без `*`). Подпись Telegram обязательна независимо от Origin, включая запросы из командной строки. Чужой пользователь, группа, истёкшая форма или потерянные права блокируют доступ; повтор запроса не повторяет списание.

## Обновление интерфейса

Выбор группы расположен в заголовке. Аватарки групп и профиля загружаются через защищённый API без раскрытия токена. На главной странице VIP/VIP+ показывается настоящая карта посёлка; без VIP карточки посёлка скрыты. Если фото или карты ещё нет, показывается понятное состояние без вымышленной иллюстрации. После обновления нужно заменить `index.html` в репозитории GitHub Pages.

Интерфейс в стиле тёмного чата: чёрный фон, графитовые панели и кнопки, белые акценты. Карты C₲ и ⚡ сохраняют голубой и фиолетовый цвета.

Сборка 0.5.0 находится в разработке. Переводы и обмен используют отдельные формы с подтверждением, магазин — категории по валютам и карточки товаров.

## Бета: скрипты и капча

Публикуйте `index.html`, `beta.js` и `beta.css` в одной папке GitHub Pages. Новые элементы доступны управляющим на главной странице группы. Скрипты по умолчанию выключены. Капчу нужно включить отдельно после приобретения подходящего тарифа; действующие участники массово не ограничиваются. Для проверки нужен основной Mini App бота, поддержка Ephemeral Messages и права ограничивать участников в супергруппе.

Публикуйте все файлы из папки miniapp: index.html, flows.js, beta.css, banners.js, banners.css, subscriptions.js, banner-font-*.css и BANNER-FONTS-LICENSE.txt (beta.js оставлен для совместимости старых клиентов). Баннеры и их медиа остаются на защищённом API. Секретные ключи не добавляются в HTML или GitHub.


## Локальный кэш

Service Worker сохраняет файлы интерфейса, встроенные иконки и шрифты. Файлы имеют версионные URL и проверку SHA-256; установка кэша атомарная. При обновлении источников выполните `python tools/build_miniapp_cache.py` и публикуйте всю папку вместе со `sw.js` и `local-cache.js`. Скрипт работает и из полного проекта, и из отдельного репозитория мини-приложения. Он воспроизводим: повторный запуск без правок даёт ту же версию. Хранятся две последние сборки. HTML проверяется по сети с HTTP-кэшированием; при обрыве сети доступна оболочка интерфейса.

Аватарки сохраняются на 6 часов, логотипы компаний — на 7 дней при поддержке CORS; неизменяемые медиа баннеров — на сутки, загруженные шрифты — на 7 дней. Данные остаются в CacheStorage аккаунта после закрытия мини-приложения. Лимит — 48 файлов и 32 МиБ, старые файлы удаляются. Авторизация проверяется сервером перед использованием пользовательского кэша; другой аккаунт получает отдельный кэш. Сам токен Telegram в хранилище не записывается. localStorage используется только для небольших предпочтений и служебных отметок. Карта посёлка остаётся в краткосрочной памяти.

Балансы, настройки, роли, каталог, капча, состояние подписок, выдача баннеров и учёт рекламных показов не сохраняются как API-снимки: запросы идут на сервер. Кэшируется только тело уже разрешённого медиа после получения актуального документа баннера. Кнопка обновления очищает пользовательский медиа-кэш и запрашивает свежие данные. Если хранилище отключено или заполнено, приложение продолжает работать через сеть.
